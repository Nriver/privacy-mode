**✨ 让你的笔记稍微私密一点**

Trilium Notes 的隐私模式小部件

- 编辑的时候可以一键模糊笔记树等区域，专心编辑文字。
- 可以主动锁定所有区域，让所有区域都模糊显示，并且不可选中。
- 支持自动锁定笔记以防你离开的时候忘记手动锁上。

# ✨ 它能做什么

## 👁️ 模糊模式

点一下笔记标题栏上的眼睛按钮就行。

会把标题、笔记树、标签页之类的东西模糊掉，浏览器标签页标题也会藏起来。再点一次就关掉。需要专心编辑的时候可以用到它。

## 🔒 锁定模式

点击锁按钮进行锁定操作，锁定之后编辑器变成只读并模糊。

笔记会变得不能修改，也不能复制。比单纯模糊覆盖得更多，笔记区域，内部链接的悬浮提示等也会藏起来。

支持启动时强制锁定，这下别人就不能从桌面直接打开Trilium看到你所有的笔记了。

## ⏱️ 自动锁定

支持自动锁定，超过一定时间不操作Trilium就会自动锁上。

默认是 5 分钟，时间可以在解锁界面自由修改。

## 🌐 多语言支持

支持英语和简体中文。

可以在解锁对话框里切换语言，选过会记住。

# 📥 安装方法

1. 从[发布页面](https://github.com/Nriver/privacy-mode/releases)下载 zip 文件。
2. 在 Trilium 中右键单击笔记树，然后点击导入，取消选中“安全导入”。
3. 重新启动 Trilium Notes，或者使用 `ctrl+r` 重新加载界面。
4. 打开任何笔记，标题栏右侧的位置看到眼睛和锁按钮。
5. 祝你玩得愉快。

# 💡 提示

1. 隐私模式的密码和你的Trilium密码是独立的不同的密码。你可以给隐私模式的密码设置一个简单方便输入的密码。
2. 自动锁定、启动时强制锁定这些选项，都在解锁对话框里，你可以根据自己的需要修改。
3. 如果你要清除密码，请阅读插件内的笔记

# 🤔 我为什么制作这个？

我不喜欢别人可以随便翻看我的笔记。

虽然Trilium它有`受保护的笔记`这个功能，但是它更倾向于加密。Trilium自身没有一个一键快速锁定的功能，任何人路过你的电脑就能直接看到你所有的笔记。如果你忘记锁定电脑，任何人只要打开桌面上的Trilium图标，就能看到你的笔记。所以我就做了这个插件，有人过来就快速模糊一下，保护一下笔记树和标题，让别人不会一眼就看到我们在做什么。离开座位就密码锁上，别人就看不了我的笔记了。当然，万一你忘记锁了，我还做了一段时间不操作也能自动锁上笔记的功能，具体可以去设置界面玩一玩。

Trilium的`受保护的笔记`还有一个问题是它的密码和你的登录密码是同一个。而在我写的这个隐私模式插件里你可以设置一个简单的独立的密码，不用和你的Trilium主密码一致。

还有一点就是这个隐私模式的各种设置是只存在于当前客户端的。于是就可以实现这种使用方法：在公司的电脑需要密码解锁，在家里自己的电脑不需要密码解锁。

总之，希望我的作品对你也有用 :)
