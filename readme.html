Privacy Mode Help

Protect your privacy

Keep your notes safe with client-side locking

🔒 About lock password

The password is stored as a hash value in the client's local storage.

Each client has a different configuration.

This is useful for cases like requiring a password at work but not at home.

🗑️ Clear password

If you forget your password, or no longer need the lock, you can erase it by doing the following:

  1. Press F12 or Ctrl + Shift + I to open Developer Tools.
  2. Copy these into the console and press Enter.
localStorage.removeItem("privacyMode_password");
localStorage.setItem("privacyMode_locked", "false");
localStorage.setItem("privacyMode_enabled", "false");
localStorage.removeItem("privacyMode_forceLock");
window.location.reload();

保护你的隐私

通过客户端锁定保护你的笔记安全

🔒 关于锁定密码

密码以哈希值的形式存储在客户端的本地存储中。

每个客户端有不同的配置。

比如你在工作时需要密码，而在家中不需要的情况会很有用。

🗑️ 清除密码

如果你忘记了密码，或者不需要锁定了，可以通过以下方式将其清除：

  1. 按下 F12 或 Ctrl + Shift + I 打开开发者工具。
  2. 在控制台输入以下内容并按回车。
localStorage.removeItem("privacyMode_password");
localStorage.setItem("privacyMode_locked", "false");
localStorage.setItem("privacyMode_enabled", "false");
localStorage.removeItem("privacyMode_forceLock");
window.location.reload();
